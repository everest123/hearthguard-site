Get started

Build your team.

My Maestro AI is a single Node.js service with no external database. It runs on a Linux machine or a Mac, at home or in your own cloud, and keeps everything in SQLite and plain files that you can read, back up and move.

Install in one command

On a Mac or a Linux machine (on Windows, inside WSL), in a terminal:

curl -fsSL https://mymaestroai.ai/install.sh | bash

Everything goes into your home folder, without sudo: its own Node.js (checksum verified), the code from GitHub, and a service that starts by itself. Then the Welcome page opens to create your account, turn on two-factor sign-in and connect your first AI.

Prefer to read it first? curl -fsSLO https://mymaestroai.ai/install.sh, open install.sh, then run bash install.sh. The same script is install/install.sh in the repository.

Four steps

From a fresh machine to a working team.

Install

Run the command above. It installs the service and opens the Welcome page, where you create your account and connect an AI. It runs under systemd or launchd and restarts itself after updates.

Meet your lead agent

Your first agent, Maestro, carries a complete map of the software. It helps you connect providers, create agents and fix anything the setup checklist flags.

Build your team

Give each agent a name, a model and a description of its role. The hub writes its identity, and you refine it as you get to know each other.

Take it everywhere

Install the phone app, turn on notifications, and connect the services your agents need. A private network such as Tailscale reaches the hub from anywhere.

What you need

  • A computer that stays on, running Linux or macOS (Windows: inside WSL). The installer brings its own Node.js.
  • At least one AI provider: a Claude or ChatGPT subscription, an API key from Anthropic, OpenAI, Google or Perplexity, or a local model.
  • Optional: Docker, for agent sandboxes.
  • Optional: an NVIDIA GPU or Apple silicon, for models that run entirely on your machine.

Installed during the private preview?

Your hub moves itself to the public repository: open Update, which offers "Move to the public repository", then restart. If Update says "Update blocked" (hubs installed before October 14, 2026), run this once in the hub folder instead:

curl -fsSL https://mymaestroai.ai/move.sh | bash

It backs up the folder first, keeps your data, workspaces, settings and agent files, and copies aside any program file you edited. Then restart the hub once.
